# E-commerce Book Scraper

A Python web scraper that collects book information from Books to Scrape and saves the results to a CSV file.

## Features

- Scrapes 1,000 books
- Extracts book titles
- Extracts prices
- Extracts ratings
- Extracts availability
- Handles pagination automatically
- Saves results to CSV

## Technologies

- Python
- Requests
- BeautifulSoup
- Pandas

## Output

The scraper produces a `products.csv` file containing:

- Title
- Price
- Rating
- Availability
